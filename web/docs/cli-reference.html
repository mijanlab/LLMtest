Reference

Command-line reference.

All commands, positional arguments, options, aliases, and defaults available in LLMtest v1.0.6.

Syntax

Command structure
llmtest [endpoint | update | uninstall] [api_key] [model_filter] [options]

Positional arguments

ArgumentDefaultDescription
endpointPromptedOpenAI-compatible API base URL.
api_keyPromptedBearer token. Optional for unauthenticated local endpoints.
model_filterEmptyCase-insensitive substring used to narrow model IDs.

Connection and management

OptionDescription
--endpoint, -eNamed alternative to the endpoint positional argument.
--key, -kNamed API-key argument.
--filter, -fNamed model-filter argument.
--version, -vPrint the installed LLMtest version and exit.
--updateUpdate LLMtest from the GitHub repository.
--uninstallRemove LLMtest from the active Python environment.

Benchmark options

OptionDefaultDescription
--prompt, -pSay hello and describe your purpose in one brief sentence.Evaluation prompt sent to each model.
--system, -sYou are a helpful assistant.System instruction for the completion.
--runs, -r1Repeated tests per model.
--concurrency, -c3Concurrent worker count.
--limit, -l0Maximum models to test; zero means all.
--timeout35Request timeout in seconds.
--max-tokens60Maximum output tokens requested.
--openOffOpen the generated HTML report.
--no-reportOffSkip writing report files.

Output options

OptionDefaultDescription
--output-html, --htmlbenchmark_report.htmlInteractive report path.
--output-mdbenchmark_report.mdMarkdown report path.
--output-csv, --csvbenchmark_report.csvCSV export path.
--output-jsonbenchmark_report.jsonRaw JSON result path.
--report, --renderEmptyRe-render reports from existing JSON.

Examples

Benchmark all models

All models
$ llmtest https://api.openai.com/v1 sk-your-key

Filter and repeat

Filtered benchmark
$ llmtest https://openrouter.ai/api/v1 sk-your-key free --runs 3 -c 2

Re-render saved JSON

Render only
$ llmtest --report benchmark_report.json --open
