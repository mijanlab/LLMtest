Analysis

Read the performance story.

LLMtest measures the streaming path from request to completion and turns the result into an interactive, portable dashboard.

Core metrics

MetricCalculationInterpretation
TTFTRequest start to first streamed chunkLower values feel more responsive in chat interfaces.
Total latencyRequest start to stream closeMeasures full task completion time.
ThroughputOutput tokens divided by generation timeHigher values indicate faster sustained generation.
Chunks/secStreamed chunks divided by generation timeShows stream fragmentation and delivery cadence.
Success rateValid non-empty runs divided by attemptsHighlights reliability, throttling, and transient failures.
Compare like with like

Use the same endpoint, prompt, token limit, concurrency, and run count when comparing models. Network conditions and provider load can change results.

Interactive HTML dashboard

The standalone HTML report is the fastest way to explore a run. It includes:

  • Search and status filters for large model catalogs
  • Table and responsive card views
  • TTFT versus throughput visual matrix
  • Speed and latency leaderboards
  • Two-to-four model head-to-head comparison
  • Detailed result inspection with error diagnostics
  • Print layout and client-side exports

Render saved results

Statuses and errors

Each model is classified as passed, partial, skipped, or failed. Authentication errors, missing access, unsupported modalities, rate limits, server failures, and timeouts are surfaced separately so a slow provider is not confused with an incompatible model.
