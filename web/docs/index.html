What is LLMtest?

LLMtest is a cross-platform Python CLI for evaluating OpenAI-compatible endpoints. It discovers available models, sends streamed prompts concurrently, measures real response timing, and generates a standalone report. The benchmark core uses Python's standard library, while the packaged CLI depends only on Requests.

Local-first by design

API keys remain in process memory, and generated HTML reports contain no external tracking or runtime dependencies.

Requirements

  • Python 3.8 or newer
  • An OpenAI-compatible base URL
  • An API key when required by the provider
  • macOS, Linux, or Windows
