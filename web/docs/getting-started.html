Guide

Your first benchmark.

Install LLMtest, connect any OpenAI-compatible endpoint, and generate an interactive performance report.

1. Install the CLI

Install directly from the GitHub repository. Use the command for your operating system.

macOS / Linux
$ pip3 install git+https://github.com/mijanlab/LLMtest.git
Windows PowerShell
$ pip install git+https://github.com/mijanlab/LLMtest.git

2. Launch interactive mode

Run the command with no arguments. The setup wizard asks for an endpoint, optional API key, model filter, and concurrency level.

Terminal
$ llmtest

Enter the endpoint

Use the base URL ending in /v1, such as https://api.openai.com/v1.

Provide credentials

Paste an API key when required, or press Enter for a local unauthenticated server.

Choose scope

Filter model IDs by a substring such as flash, free, or gpt.

Run and review

Results stream into the terminal, then reports are written to the current directory.

3. Run with arguments

For automation or repeatable testing, pass values directly.

Direct benchmark
$ llmtest https://api.openai.com/v1 sk-your-key gpt --concurrency 3 --runs 2 --open
Avoid shell history for production keys

Interactive mode keeps the key out of the command line. For shared machines, prefer the prompt instead of passing a secret as an argument.

Update or uninstall

Maintenance
$ llmtest update
$ llmtest uninstall
